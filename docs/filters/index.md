# Filters

Every filter page follows the same twelve headings, from a plain overview to the tests and the references. Facts such as the parameters, the formula and the status come from the catalog. Kernels, figures and worked examples come from the filter code itself. So a page always describes the filter that runs.

The table lists the filters that have a page. The other catalog entries are planned and get their pages when they are built.

## How to read a filter page

- **Overview** says what the filter is for and shows its effect on a test image.
- **How it works** explains the steps in plain words.
- **Mathematical foundation** gives the formula with the default values, and defines every symbol.
- **Kernel or operator** shows the kernel, the window or the curve, as the Inspector does.
- **Worked example** follows one pixel through the filter, with numbers from the real code.
- **Tests** names the reference library and the tolerance.

See [Convolution and correlation](../mathematics/convolution-and-correlation.md) for the conventions all kernel filters share.
