# Keyboard shortcuts

The studio shows the same list under **Help > Keyboard shortcuts** (Ctrl+/ or Cmd+/). The command palette (Ctrl+K or Cmd+K) also shows the shortcut next to each command.

Shortcuts with Ctrl or Cmd work anywhere, except while you type in a text field. Single-letter tool keys work when the focus is not in a field or a menu.

## Commands

A unit test compares this table with the command list in the studio, so the two stay the same.

| Command | Menu | Windows and Linux | macOS |
|---|---|---|---|
| Open... | File | `Ctrl+O` | `Cmd+O` |
| Paste image | File | `Ctrl+V` | `Cmd+V` |
| Export... | File | `Ctrl+S` | `Cmd+S` |
| Undo | Edit | `Ctrl+Z` | `Cmd+Z` |
| Redo | Edit | `Ctrl+Shift+Z` | `Cmd+Shift+Z` |
| Deselect | Select | `Ctrl+D` | `Cmd+D` |
| Apply selected filter | Filter | `Ctrl+Enter` | `Cmd+Enter` |
| Zoom in | View | `Ctrl++` | `Cmd++` |
| Zoom out | View | `Ctrl+-` | `Cmd+-` |
| Fit on screen | View | `Ctrl+0` | `Cmd+0` |
| Actual size (100%) | View | `Ctrl+1` | `Cmd+1` |
| Pixel grid | View | `Ctrl+'` | `Cmd+'` |
| Hand | View > Tools | `H` | `H` |
| Zoom | View > Tools | `Z` | `Z` |
| Pixel probe | View > Tools | `I` | `I` |
| Command palette | Help | `Ctrl+K` | `Cmd+K` |
| Keyboard shortcuts | Help | `Ctrl+/` | `Cmd+/` |

Deselect works from Phase 4, when the selection tools arrive.

For zoom, the + key works with or without Shift, and the = key works too.

## Canvas

| To do this | Press or do this |
|---|---|
| Pan with any tool | Hold `Space` and drag |
| See the original image | Hold `\` |
| Pan the focused canvas | Arrow keys. Add `Shift` for larger steps. |
| Zoom at the pointer | `Ctrl`, `Cmd` or `Alt` with the mouse wheel, or pinch |
| Scroll sideways | `Shift` with the mouse wheel |
| Pan | Drag with the middle mouse button |
| Fit the image | Double-click with the Hand tool |
| Show 100% | Double-click with the Zoom tool |
| Zoom out with the Zoom tool | `Alt` and click |

## Dialogs and menus

- `Esc` closes a menu, a dialog or the command palette.
- In the command palette, the arrow keys move through the results and `Enter` runs one.
- In a number field, the up and down arrow keys change the value by one step. Add `Shift` for ten steps. `Enter` applies a typed value and `Esc` cancels it.
