# Model reference

Every learned model PixelNexus can use is listed in `catalog/models.yaml`. The owner approved each one after a license review, recorded in `planning/MODEL_REVIEW.md`. The tables below are generated from the catalog, so they always match it.

Nothing downloads on its own. A model downloads only when you click its Download button, and every file is checked against its SHA-256 before it is kept.

## Models

"Runs in" says where the model can run today. The browser runs only ONNX files. "Phone" marks models small enough to run in a phone browser.

## Licenses

Each license link goes to the license of the project that publishes the file. Two models allow non-commercial use only: the structured edge forest and PiDiNet. PixelNexus is a study project, so the owner chose to keep them. If you use PixelNexus for paid work, do not use those two. Their filters say so next to the Download button.

The model files are never stored in the PixelNexus repository. They download to your computer or browser from their own source.
