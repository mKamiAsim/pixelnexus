# Blog

`medium-post.md` is a post for Medium about PixelNexus. It is not part of the docs site.

Medium does not read local image paths. When you paste the post, upload each PNG from `images/` where its image line is.

The screenshots come from the studio itself. To make them again, run `pnpm dev`, then `node web/scripts/blog-shots.mjs` from the repository root.
